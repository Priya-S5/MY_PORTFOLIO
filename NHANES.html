06 / Code Example

Example: deriving health-related features

The following Python example illustrates how NumPy can be used to calculate BMI and waist-to-height ratio from measurement arrays. Replace the sample values with appropriately cleaned dataset columns when running the analysis. 

import numpy as np
import matplotlib.pyplot as plt

# Illustrative measurements only.
# Replace these values with cleaned NHANES data columns.
height_cm = np.array([170, 165, 180, 158, 175], dtype=float)
weight_kg = np.array([68, 60, 82, 54, 75], dtype=float)
waist_cm = np.array([82, 74, 94, 68, 88], dtype=float)

# Convert height from centimetres to metres
height_m = height_cm / 100

# Derive BMI
bmi = weight_kg / (height_m ** 2)

# Derive waist-to-height ratio
waist_to_height = waist_cm / height_cm

# Inspect the derived features
print("BMI:", np.round(bmi, 2))
print("Waist-to-height ratio:",
      np.round(waist_to_height, 3))

# Visualize the BMI distribution
plt.hist(bmi, bins=5, edgecolor="black")
plt.xlabel("BMI")
plt.ylabel("Frequency")
plt.title("BMI Distribution — Illustrative Data")
plt.tight_layout()
plt.show()
Important: The values in this snippet are illustrative, not actual NHANES participant records. For real analysis, confirm units, handle missing or invalid values, and follow the dataset's documentation before calculating derived features.
